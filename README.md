## ✨ 主要功能

- **🖼 会动的海报墙** —— 上万部影片瀑布流呈现,秒级搜索 / 筛选 / 排序;虚拟滚动,再大的库也顺滑。
- **🤖 AI 智能识别刮削** —— 文件名再乱也能认出是哪部,自动匹配 TMDB 海报、简介、评分、年份与演职员。

- **🔎 查漏补缺** —— 一眼看清自己收了什么、还缺什么,顺着影史与片单一路补下去。
- **🎞 内置高清播放** —— mpv 内核硬解,整理好双击即看,字幕 / 音轨 / 剧集一键切换。
