# 西天电影会 · CINEHALL

**整理你自己的片库,发现整个电影世界。** 一款把散落在网盘 / NAS / 本地的自有影片,理成一座私人影院的桌面工具。再用合集、榜单、演员与 AI 搜片铺开整个电影世界的片单,看清自己收了什么、还缺什么。

> 工具本身不提供任何影片或片源,只整理你已经拥有的影片。

## 下载

前往 **[Releases](../../releases/latest)** 下载最新的 Windows 便携版:

- 解压后双击 `CineHall.exe` 即可运行,**免安装**。
- 绿色软件:所有配置、缓存、影库索引都写在程序文件夹的 `data\` 里;整个文件夹拷到别的电脑或移动硬盘,打开就还是原来的样子。
- 首次打开会有配置引导,按提示配好 TMDB Key 和片库位置即可。

## 亮点

- **会动的海报墙** —— 万部影片瀑布流,秒级检索、筛选、排序;虚拟滚动,再大的库也顺滑。
- **AI 智能识别** —— 文件名再乱也能认出是哪部,自动匹配 TMDB 元数据、海报、简介与评分。
- **演员墙与画像** —— 按演员聚合作品,一页看尽某位演员的生涯、获奖与深度合作关系。
- **合集与榜单** —— 系列自动成集,内置获奖 / 榜单配方,像策展人一样编排你的片库。
- **内嵌高清播放** —— mpv 内核硬解 4K,字幕 / 音轨 / 剧集一键切换。
