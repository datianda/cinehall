## 📖 这是什么

很多影迷都有同一个烦恼:攒了几百上千部电影,散落在硬盘、移动盘、NAS、网盘里 —— 文件名乱七八糟、没有封面、哪部看过哪部没看全靠脑子记、想找一部翻半天、甚至重复下载了都不知道。

**西天电影会**就是专门解决这个问题的桌面工具。它做两件事:

1. **整理**:把你已有的影片,自动识别、刮削元数据、生成封面,理成一座漂亮、好搜、好逛的海报墙,像整理相册一样收纳你的收藏。
2. **发现**:再用演员、系列、合集、榜单,把整个电影世界的片单铺在你面前 —— 一眼看清自己**收了什么、还缺什么**,顺着影史与奖项一路补下去,像一堂看不完的私人电影课。

> 它不是看片软件、也不提供任何影片或片源;它是帮你把**自己已经拥有**的电影,整理好、看明白的工具。

## ✨ 核心功能详解

### 🖼 会动的海报墙影库

- **万部规模不卡顿**:瀑布流呈现整库影片,虚拟滚动技术让上万部的库也能顺滑滑动。
- **秒级检索**:库内搜片名即时出结果;支持按**分类**(电影 / 剧集 / 其他)、**题材**(爱情 / 动作 / 科幻 / 悬疑…)、**国家地区**、**年代**多维筛选,层层组合快速定位。
- **多种排序**:按入库时间、评分、年份等排序,想怎么逛就怎么逛。
- **电影 + 剧集混合**:剧集自动标集数,和电影同库共存、统一管理。
- **主题皮肤**:内置霓虹 / 玻璃 / 胶片等多套配色,海报墙也能换心情。

### 🤖 AI 智能识别与刮削

- **文件名再乱也能认**:`[电影天堂]阿凡达.2009.1080p.BluRay.x264` 这种乱名,也能准确认出是哪部。
- **一键补全元数据**:自动匹配 TMDB 的海报、简介、评分、上映年份、类型、导演与演职员表,空荡荡的文件夹瞬间变成图文并茂的收藏。
- **批量 + 单片两种模式**:整库批量归档,也能对个别影片手动单片识别、纠正匹配。
- **识别历史可还原**:每次识别 / 归档都有记录,认错了、归档错了,一键还原回上一步,不怕误操作。

### 👤 演员墙与生涯画像

这是收藏党最爱的功能。点开任意一位演员,一整页给你铺开:

- **生平与档案**:生日、出生地、简介,以及 Ta 的**获奖与提名**记录。
- **库内常合作**:统计出「谁和 Ta 同框最多」,一眼看清你库里的班底关系。
- **全部作品 + 已有 / 缺标记**:Ta 参演的**每一部**都列出来,并标好哪些你**已有**、哪些**还缺** —— 照单补片、收藏不漏一部。
- **深挖全生涯**:一键扫 Ta 的全部作品做同框统计,把演员之间的合作网络摸透。

### 🧱 多片同屏 · 会动的影片墙

不止能一部一部看 —— 还能让好几部**同时播放**,拼成一面流动的光影墙:

- **同时播放多部**:在详情页或海报墙上把影片「加入影片墙」,每部缩成一个平铺小窗,**多路一起放**。
- **活的展厅**:几部片子一起动起来,不是静态封面,是一面会动的海报墙,随手截图都好看。
- **随开随清**:想看几部就加几部,不看了一键清空所有小窗。

### 🅰 AI 字幕(本地 Whisper 自动生成)

给没有字幕、或只有外语音轨的片子,**在本地把字幕「听」出来**,全程离线、不上传任何音视频:

- **一键装好环境**:App 内置向导,自动下载并配置 Whisper(whisper.cpp)+ ffmpeg + 语音模型,装好即用,不用自己折腾命令行。
- **自动生成字幕**:选一部没字幕的片,让它在本地听写,几分钟生成一份字幕,直接挂到播放器上。
- **多档模型可选**:提供不同大小的语音模型,在**速度**与**精度**之间自由权衡;支持 **CUDA GPU 加速**(有独显更快)。
- **双语翻译**:可把听写出的字幕翻成中英**双语对照**,外语片、纪录片也能舒服看。

### 📱 手机 / 平板也能看(局域网 Web)

- **浏览器直接看片库**:开启局域网访问后,手机 / 平板 / 另一台电脑用浏览器就能浏览你的海报墙、搜片、看详情。

## 🚀 初始化与快速开始

第一次用大概 5 分钟配好,之后打开即用。全程有引导,不用啃文档。

**① 下载与打开**<br>
到 [Releases](../../releases/latest) 或[官网](https://lifeisshortplaymore.com)下载 Windows 便携版,解压,双击 `CineHall.exe`(macOS 见官网说明)。首次打开若弹「未知发布者」,点「更多信息 → 仍要运行」即可(绿色软件、已签名,无害)。

**② 填 TMDB Key**<br>
海报、简介、评分、演职员这些资料来自 TMDB。首次会引导你填一个**免费的 TMDB API Key**(官网有申请方法,几分钟搞定),一次配置、长期使用。

**③ 指定你的片库位置**<br>
告诉它影片放在哪 —— 本地文件夹 / 移动盘 / NAS / WebDAV / 网盘都行,可以加多个。它按你指定的位置去扫描,不必把几 TB 的库搬来搬去。

**④ 装播放内核(mpv)**<br>
播放用的是专业的 mpv 内核。本机若没有,App 会**引导一键安装**(Windows 走 winget 一步到位),也可以指定一个现成的 mpv,或先用简易播放顶着。

**⑤(可选)装 AI 字幕环境**<br>
需要本地自动生成字幕时,在设置里点一下,App 自动下载配置 Whisper 环境(whisper.cpp + 模型 + ffmpeg)。用不到可以先跳过,随时再装。

**⑥ 扫描,成墙**<br>
让它扫描识别,自动刮削海报与资料,几分钟后你的海报墙就成型了 —— 开逛吧。

> 所有配置与索引都存在程序文件夹里;整个文件夹拷到别的电脑或移动硬盘,打开还是原来的样子。
